* CLJS WebGL2 Demo
A small WebGL2 demo written in [[https://clojurescript.org][ClojureScript]] using [[https://shadow-cljs.org][shadow-cljs]].  Content of the
demo is really taken from [[https://webgl2fundamentals.org/][webgl2fundamentals.org]].
